Movimentação com blocos personalizados

Diferente dos meteoros, o Chefe usa números aleatórios para que o jogador não consiga prever para onde ele vai fugir.

O Poder do Aleatório Ao usar o bloco "número aleatório", o Chefe nunca faz o mesmo caminho. Isso torna a batalha muito mais desafiadora!
Dica Técnica:
Para mover para a esquerda, subtraímos um número aleatório de X. Isso cria um deslocamento negativo no plano cartesiano.
