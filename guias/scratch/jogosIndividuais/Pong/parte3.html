Placar do jogador

`Primeiramente, vamos criar uma variável para armazenar os pontos do jogador chamada `Pontos_player`.

Sistema de Gol
se posição x > 220 então
  adicione 1 a Pontos_player
  vá para x: 0 y: 0
  mude ball_speed para 5

Explicação passo a passo:

  • O Radar (posição x > 220): O computador fica vigiando se a bola passou da linha de fundo da direita. É como um juiz de futebol olhando a linha do gol!
  • O Placar (adicione 1): Toda vez que a bola passa dali, o computador grita "GOL!" e coloca mais um ponto na sua conta.
  • O Teletransporte (vá para x:0 y:0): Para o jogo não acabar, a bola é teletransportada de volta para o meio do campo instantaneamente.
  • O Freio (ball_speed para 5): Se a bola estiver rápida demais, aqui nós damos uma "segurada" nela para a nova rodada começar justa.
Dica de Ouro: O bloco "Sempre" é como um motor que nunca desliga. Se você esquecer dele, o computador só vai checar o ponto uma única vez e depois vai tirar um cochilo! 😴

Transformando em um Jogo Completo

Agora que você já domina o radar de pontos, é hora de transformar seu projeto em um jogo completo! Marque cada conquista:

  • O Grande Campeão (Vitória/Derrota): Crie uma regra: SE Pontos_player = 5, ENTÃO transmita a mensagem "Vitoria" e pare todos os sons! Dica: Use um novo "Apoio" (Sprite) para escrever "VOCÊ VENCEU!" na tela.
  • O Portal de Início (Tela Inicial): O jogo não pode começar "do nada"! Crie um botão de JOGAR. A bola e as raquetes só devem aparecer quando o botão for clicado. Desafio: Use o bloco "quando este ator for clicado".
  • Modo Cooperativo (Co-op): Que tal jogarem em dupla contra o computador? Adicione uma segunda raquete que se move com as teclas W (para subir) e S (para descer). Dica: Vocês precisam proteger o mesmo lado do campo!
