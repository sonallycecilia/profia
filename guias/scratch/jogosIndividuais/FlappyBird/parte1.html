Flappy Bird: Primeiros Passos

Visão Geral do Jogo Flappy Bird é um jogo bidimensional de sobrevivência infinita. O objetivo principal é manter o personagem no ar enquanto navega por uma série de obstáculos gerados continuamente. A tela se move para a esquerda, dando a impressão de que o pássaro está voando para a frente.

Importando e Organizando Fantasias

Como você já domina a criação de jogos, sabe que o segredo do movimento está na organização. Vamos transformar imagens estáticas em personagens vivos usando as Fantasias!

Sprites Dinâmicos

Um único Ator pode guardar várias "roupas" ou poses dentro dele. Isso facilita muito a sua programação:

  • Animação de Voo: No mesmo objeto do passarinho, carregue as fantasias de "asa para cima" e "asa para baixo".
  • Variedade de Obstáculos: Use o mesmo Ator para os canos, alternando entre as fantasias de "cano para cima" e "cano para baixo".

Movimentação: A Gravidade e o Pulo

No mundo real, quando você solta um objeto no ar, ele não cai com velocidade constante: ele vai ficando cada vez mais rápido conforme despenca. Isso acontece por causa da gravidade, que empurra tudo para baixo o tempo todo. É exatamente essa sensação que queremos recriar no nosso pássaro!

Para simular a gravidade no Scratch, usamos duas ideias trabalhando juntas dentro de um laço sempre:

  • Velocidade: uma variável que diz o quanto o pássaro se move para cima ou para baixo a cada instante.
  • Aceleração: a cada repetição do laço, tornamos essa velocidade um pouquinho mais negativa. Assim a queda começa lenta e vai ganhando força, igualzinho na vida real.

Veja como montar esse comportamento passo a passo:

  • Defina a posição inicial no eixo X e Y para o herói não começar perdido.
  • Crie a variável velocidadeY para controlar a velocidade vertical.
  • Dentro de um laço "sempre", adicione o valor de velocidadeY ao eixo Y e depois diminua 1 dessa variável para criar aceleração.
  • Use o bloco aponte para direção para inclinar o personagem para baixo, simulando a queda.

Da Física para o Código

O legal é que a gravidade não empurra o pássaro direto para baixo. Ela faz assim, em dois passinhos que se repetem sem parar:

velocidade = velocidade − gravidade
A cada instante, a velocidade é diminuída um pouquinho pela gravidade, por isso o pássaro vai perdendo o impulso de subida. Como a velocidade vai ficando cada vez mais forte para baixo, o passarinho cai cada vez mais rápido, igualzinho na vida real!
↓
posição Y = posição Y + velocidade
Só depois a posição do pássaro é atualizada, somando essa velocidade, é ela que faz o pássaro realmente subir ou cair na tela.

O Pulo do Pássaro

Imagine que o passarinho é um foguetinho! Toda vez que você aperta a tecla espaço, é como se ele ganhasse um empurrão para o céu. E quando você solta a tecla? A gravidade que criamos antes assume o comando e puxa o passarinho de volta para baixo. É essa briga entre o pulo e a gravidade que deixa o Flappy Bird tão divertido!

  • aponte para direção -45: o pássaro levanta a cabecinha e olha para cima na hora do pulo!
  • mude velocidadeY para 5: essa é a força do pulo. O número 5 é o "tamanho" do empurrão que joga o passarinho para cima. Quanto maior o número, mais alto ele voa!
  • adicione velocidadeY a y: aqui o passarinho realmente sobe na tela, usando a força que a gente acabou de dar para ele.
  • aponte para direção -15: é só uma inclinação mais suave, para o pássaro não ficar olhando reto para cima e continuar com um jeitinho bonito de voar.
