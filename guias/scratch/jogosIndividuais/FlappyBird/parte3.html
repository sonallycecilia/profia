Sistema de Pontos e Desafios

Até aqui, você já tem um pássaro que voa e canos que aparecem para desviar. Mas todo jogo precisa de um objetivo: uma forma de saber se estamos indo bem ou mal! Nesta parte, vamos transformar o nosso Flappy Bird em um jogo de verdade, com placar para contar seus acertos e sugerir alguns outros desafios.

Score

Antes de tudo, crie uma variável chamada Score. Toda vez que você clica na bandeira verde para começar uma partida nova, a variável do placar (score) precisa voltar para zero.

ZERANDO O PLACAR
Quando bandeira verde for clicado
 ➜ mude score para 0

Como fazer os pontos?

Como o computador sabe que você conseguiu passar pelo cano? O cano anda pela tela da direita para a esquerda. O código manda o cano esperar até chegar em uma linha imaginária bem lá atrás (a posição X igual a -200). Se o cano chegou lá inteirinho, é porque o pássaro passou por ele em segurança e você ganha um ponto!

MARCANDO PONTOS
Quando eu começar como um clone
 ➜ sempre
espere até que posição x = -200
adicione 1 a score
Curiosidade de Game Design: Usar uma posição específica da tela (como o X em -200) é um truque muito comum nos jogos para criar "linhas de chegada" invisíveis.

Desafio 3: Telas de Início e de Derrota

Todo jogo profissional tem uma tela de início (aquela que espera você apertar "Jogar") e uma tela de derrota (o famoso "Game Over"). Para fazer isso no Scratch, usamos dois truques poderosos: um botão que o jogador clica e a troca de cenário, que avisa todos os personagens em qual "momento" do jogo estamos.

Quando o Cenário Mudar Para...

Pense no cenário como o palco da peça: quando ele troca, todo mundo sabe que a cena mudou. No Scratch, cada sprite pode usar o bloco de evento quando o cenário mudar para para reagir na hora certa. Assim, ao trocar o cenário para "Jogo", o pássaro começa a jogar; ao trocar para "Game Over", a tela de derrota aparece. É esse bloco que liga o botão ao jogo inteiro!

1. Botão "Jogar"

Crie um sprite de botão. Ele aparece na tela de início e, quando clicado, troca o cenário para "Jogo": o aviso de que a partida vai começar.

SPRITE DO BOTÃO
Quando bandeira verde for clicado
 ➜ mude o cenário para Início
 ➜ mostre

Quando este sprite for clicado
 ➜ mude o cenário para Jogo
 ➜ esconda

Começando o Jogo

O pássaro e os canos ficam parados/escondidos até receberem o aviso do botão. Só aí o jogo ganha vida!

SPRITE DO PÁSSARO
Quando bandeira verde for clicado
 ➜ esconda

Quando o cenário mudar para Jogo
 ➜ mostre
 ➜ mude vidas para 3
 ➜ mude score para 0

Tela de Derrota (Game Over)

Quando as vidas chegarem a zero, o pássaro troca o cenário para Game Over. A tela de derrota reage a essa mudança e aparece na hora.

QUANDO AS VIDAS ACABAM (Pássaro)
Se vidas = 0 então
➜ mude o cenário para Game Over
➜ esconda
➜ pare outros scripts do sprite
TELA DE DERROTA (Sprite do botão)
Quando o cenário mudar para Game Over
 ➜ mostre
Dica: Repare que é o mesmo botão que reaparece no Game Over! Como ele já está programado para trocar o cenário para "Jogo" quando clicado, o jogador pode tentar de novo na hora — sem precisar apertar a bandeira verde de novo.
Missão Extra: Na tela de derrota, mostre o texto "Recorde: " junto com a variável Recorde do Desafio 2. Assim o jogador vê se bateu o próprio recorde!

Hora dos Desafios!

Agora que o seu jogo já conta pontos, que tal deixá-lo ainda mais completo? A seguir vêm alguns desafios para você turbinar o seu Flappy Bird. Escolha um, tente sozinho e, se travar, fale com o professor. Bora lá?

Desafio 1: Vidas

Para o jogo não acabar na primeira batida, vamos criar um sistema de corações. Mas cuidado: sem um "tempo de respiro", o pássaro perderia todas as vidas em um milissegundo!

CONTROLE DE DANO (No Pássaro)
Se tocando em Canos então
➜ adicione -1 a Vidas
➜ repita 5 vezes
esconda
espere 0.2 segs
mostre
espere 0.2 segs
O Truque do Piscar

O bloco Repita cria o "Tempo de Invencibilidade". Enquanto o pássaro pisca, o código está ocupado e não consegue tirar mais vidas, dando tempo para o jogador se recuperar do susto!

+ Sugestões: Crie um efeito sonoro de "batida" quando o pássaro perde uma vida, adicione uma verficação quando a vida do pássaro chegar em 0 mudar para um cenário de derrota.

Desafio 2: Variável Recorde

Sabe aquele "melhor placar" que os jogos guardam? Vamos criar uma variável Recorde que só aumenta quando você faz uma pontuação maior do que a sua melhor marca. Diferente do score, o recorde não volta para zero quando começa uma partida nova — ele fica guardado!

GUARDANDO O RECORDE
Se score > recorde então
➜ mude recorde para score
Dica: Coloque essa verificação no momento em que o jogo termina (quando o pássaro perde todas as vidas). Assim o jogo compara o seu placar final com o recorde antigo e só troca se você foi melhor!

Desafio 3: Recompensas

Um jogo fica muito mais divertido quando temos algo para coletar! Que tal criar moedas que surgem entre os canos e dão pontos extras? A ideia é usar clones, igual fizemos com os canos. Pense na lógica:

  • Uma "moeda mãe" fica escondida e vai criando clones de tempos em tempos, lá na direita da tela.
  • Cada clone anda para a esquerda na mesma velocidade dos canos (se o cano anda -5, a moeda também).
  • O resto é com você! Use a criatividade e lógica aprendida nas aulas.
Missão Extra: Crie uma "Moeda de Ouro" rara que vale 5 pontos, mas que aparece muito menos vezes que a moeda comum!
