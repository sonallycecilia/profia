Os clones

Na aula anterior a gente montou o cenário e fez o dino ganhar vida. Ele corre no lugar trocando entre as fantasias Walk 1 e Walk 2, o chão rola para trás sem parar com dois pedaços que se revezam, e o pulo funciona pela física da gravidade, usando a velocidade de pulo e a linha do chão. Agora o deserto já se mexe. Só falta uma coisa: encher a tela de obstáculos. E é para isso que servem os clones.

O que é um Clone?

Um clone é uma cópia de um sprite feita durante o jogo. Pense numa máquina de xerox: existe um desenho original e a máquina vai soltando cópias iguaizinhas dele. No Scratch a ideia é a mesma, mas com um detalhe importante: cada cópia sai "viva", ou seja, aparece na tela e roda o próprio código sozinha.

É isso que vai resolver o nosso problema. Para encher o deserto de cactos, a gente não precisa desenhar um sprite para cada um. Basta ter um cacto só e pedir para o Scratch ir criando clones dele.

O Chefe da Fábrica

O cacto original nunca aparece no jogo e nunca colide com nada. O trabalho dele é ficar escondido só fabricando clones! Veja como funciona o motor da fábrica:

  • O Chefe se esconde para ninguém ver ele.
  • Ele entra num ciclo sempre (trabalha sem parar!).
  • Ele espera um tempo surpresa (entre 0.7 e 1.8 segundos). Assim, você nunca sabe quando o próximo cacto vai aparecer!
  • E plim! Ele cria um clone dele mesmo.
LIGANDO A FÁBRICA
Quando bandeira verde for clicado
 ➜ esconda
 ➜ sempre
➜ espere número aleatório entre 0.7 e 1.8 seg
➜ crie clone de este ator
Dica Secreta: Usar o bloco verde de "número aleatório" deixa o jogo muito mais divertido, porque os cactos não aparecem todos no mesmo ritmo chato de relógio!

Modelo x Cópias

Dois papéis bem diferentes

Vale separar bem quem é quem: o modelo é o cacto original, escondido, que só serve pra criar cópias, e ele nunca corre nem bate. As cópias (clones) são os cactos que de fato aparecem, andam e desviam. E a melhor parte: cada clone tem vida própria. Eles não precisam saber uns dos outros, então dá pra ter vários cactos na tela ao mesmo tempo usando um sprite só!

A Vida de um Clone

Quando o clone nasce, ele precisa saber onde aparecer, que roupa vestir e para onde ir!

Depois de vestir a fantasia, o clone tem uma missão só: atravessar a tela para a esquerda e sumir!

  • Ele anda para trás um pouquinho por vez (-10 no X), no mesmo ritmo do chão.
  • Ele repete isso até chegar bem no limite esquerdo da tela (X menor que -230).
  • Quando passa da borda, ele é apagado. Assim os clones não vão se acumulando e travando o computador.
O CLONE EM AÇÃO
Quando eu começar como um clone
 ➜ mostre
 ➜ vá para x: 260 y: -127
 ➜ mude para a fantasia número aleatório entre 1 e 5
 ➜ repita até que posição x < -230
➜ adicione -10 a x
 ➜ apague este clone
Lembra do chão? Os cactos andam -10 por vez, exatamente na mesma velocidade do chão que você montou anteriormente. Por isso parece que eles estão "grudados" no piso, correndo junto com o cenário!

O Jogo da Aleatoriedade

Cada cacto é um sorteio

Repara que a nossa fábrica joga aleatoriedade a cada cacto: um decide quando o próximo nasce (o tempo de espera entre 0.7 e 1.8 segundos) e o outro decide qual a aparência dele (a fantasia de 1 a 5). É essa dupla de sorteios que impede o jogo de ficar decorável e faz cada partida ser diferente da anterior!

As Nuvens

As nuvens funcionam quase igual aos cactos: também nascem de clones. Mas elas têm dois detalhes especiais que dão charme ao cenário.

1. Ficam lá atrás

As nuvens vão para a camada de trás, atrás de tudo. Assim o dino e os cactos passam na frente delas, como num cenário de verdade.

2. São bem preguiçosas

Enquanto o chão anda -10 por vez, a nuvem anda só -1. Ela se arrasta pelo céu bem devagarinho.

A NUVEM PREGUIÇOSA
Quando eu começar como um clone
 ➜ vá para camada de trás
 ➜ vá para x: 240 y: número aleatório entre 60 e 150
 ➜ repita até que posição x < -230
➜ adicione -1 a x
 ➜ apague este clone
A Sensação de Profundidade

Repara no truque: o que está perto (chão e cactos) se move rápido, e o que está longe (nuvens) se move devagar. Nossos olhos entendem esse contraste como distância! É o mesmo efeito de olhar pela janela do carro: os postes na beira da estrada passam voando, mas a lua lá longe parece quase parada.

Fábrica de nuvens: igual à dos cactos, o modelo da nuvem fica escondido criando clones num ciclo sempre, só que com uma pausa maior entre um e outro (a cada 4 segundos), porque o céu não precisa ficar lotado.
