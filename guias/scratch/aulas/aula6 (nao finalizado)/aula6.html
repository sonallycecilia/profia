Variáveis

Você sabia que o computador tem uma memória meio curta? Se a gente não pedir para ele guardar as coisas, ele esquece tudo na mesma hora! Para resolver isso, usamos as VARIÁVEIS.

O que é uma Variável?

Conceito Mágico Uma Variável é como uma Caixinha Mágica.
1. Você dá um NOME para a caixa (Etiqueta).
2. Você guarda algo dentro dela.
3. Você pode trocar o que está dentro a qualquer hora (Variação).

Como funciona:

Imagine que você pegou uma moeda.

Memória (Antes)
A caixa [Pontos] guarda: 10

Agora pegou outra moeda! O 10 sai e entra o 20.

Memória (Depois)
A caixa [Pontos] guarda: 20

No Scratch:

Usamos os blocos laranjas escuros.

Bloco de Variável
mude [Pontos] para 0
...
adicione 1 a [Pontos]

O nome "Pontos" é a etiqueta da caixa!

Os Tipos de Tesouros

O que podemos guardar nessas caixinhas? No Scratch, são três coisas principais:

  • Números: Pontos, Vidas, Tempo. Ex: 10, 50, 100.
  • Palavras (Texto): Nome do jogador, uma frase. Ex: "Maria", "Game Over".
  • Booleano (Interruptor): Só tem dois jeitos: SIM ou NÃO (Verdadeiro ou Falso). Ex: A porta está aberta? Sim.

Entrada e Saída

Agora que o computador já tem memória (as caixinhas), precisamos aprender a conversar com ele!

ENTRADA (Input): O Computador Ouve

É quando VOCÊ fala algo para o computador. É como se ele tivesse ouvidos.

O computador faz uma pergunta e espera você digitar.

Sensores (Azul Claro)
pergunte "Qual seu nome?" e espere

O que você digitar vai para uma caixinha especial chamada "resposta".

⌨️

Você usa o teclado para "entrar" com os dados.

2. SAÍDA (Output): O Computador Fala

É quando o computador responde para você. Ele usa a tela para mostrar o resultado.

💬

O Gatinho mostra um balão de fala.

Existem dois jeitos do Gato falar:

Aparência (Roxo)
diga "Olá!" por 2 segundos
(Balão de Fala 🗣️)

pense "Hummm..." por 2 segundos
(Balão de Pensamento 💭)
O Grande Truque Podemos juntar tudo! O computador PERGUNTA (Entrada), guarda na VARIÁVEL (Memória) e depois FALA seu nome (Saída).
