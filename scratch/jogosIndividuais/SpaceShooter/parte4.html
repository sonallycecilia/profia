Ajustes e Refinamento do Space Shooter

Agora que o jogo está completo, vamos fazer pequenas melhorias para deixá-lo mais atraente e funcional!

Sistema de Vidas da Nave

No início do projeto, qualquer toque em um meteoro causava Game Over imediato usando o bloco "pare todos". Vamos transformar isso em um sistema de Vidas (HP)!

Preparação Vá na aba Variáveis e crie uma nova variável chamada Vidas para todos os atores.
INÍCIO DO JOGO
quando 🚩 for clicado
➜ Defina Vidas para 3
NOVO COLLISION CHECK
quando 🚩 for clicado
sempre
se tocando em Meteors? ou Enemy? então
➜ adicione -1 a Vidas
➜ vá para x: 0 y: -140 // Volta pro meio
➜ espere 1 seg
se Vidas < 1 então
➜ pare todos // Agora sim, Game Over!
⚠️ Atenção: Ao trocar espere até que por sempre > se, nós permitimos que o jogo continue verificando a colisão várias vezes até a vida acabar!

Inimigo "Kamikaze" (Rastreador)

Meteoros aparecem em sequência, mas este novo alienígena vai perseguir ativamente a nave do jogador!

  • Desenhe ou escolha um novo Ator para ser o Inimigo Rastreador.
  • Use o bloco de repetição sempre para criar o movimento de perseguição.
MOVIMENTO RASTREADOR
quando eu começar como clone
sempre
➜ aponte para Nave
➜ mova 3 passos
Cuidado!
Como ele aponta para a nave, ele pode girar de cabeça para baixo. Mude o estilo de rotação do ator para "esquerda-direita" se não quiser que ele gire completamente!

Power-Up de Tiro Duplo

Vamos criar um item que, quando coletado, melhora os tiros da nave temporariamente.

Lógica de Estado Vamos usar uma variável para "lembrar" se o poder está ativado (1) ou desativado (0).
  • Crie uma variável chamada Tiro_Especial.
  • Crie um novo ator chamado PowerUp (pode ser uma estrela ou raio). Faça-o cair do topo da tela igual aos meteoros.
  • No código do PowerUp, adicione: se <tocando em [Nave]> então ➜ transmita [Ativar_Poder] e apague este clone.
CÓDIGO DA NAVE - RECEBENDO O PODER
quando eu receber Ativar_Poder
➜ mude Tiro_Especial para 1
➜ toque o som PowerUp
➜ espere 5 seg // Duração do poder!
➜ mude Tiro_Especial para 0

Desafio: No código do seu Laser, use um bloco se ... senão. Se Tiro_Especial for 1, crie dois clones do laser com posições X diferentes!

Além disso, você pode usar sua imaginação e adicionar outros itens com poderes especiais!

Escudo de Energia (Vidas do Chefe)

O Chefe não deve ser derrotado com apenas um tiro! Vamos dar a ele uma barra de vida (HP) para a batalha durar mais.

  • Vá na aba Variáveis e crie uma nova variável chamada Vida_Boss.
  • No script de entrada do Boss (quando eu receber "Phase4"), adicione o bloco mude [Vida_Boss] para 5.
  • Encontre o script de colisão (onde ele toca no Laser). Em vez de explodir na hora, coloque o bloco adicione -1 a [Vida_Boss].
  • Adicione um bloco se <(Vida_Boss) < 1> então e mova os blocos de explosão e transmita boss down para dentro dele!

Criando a Tela de Vitória

  • Crie um novo Ator chamado Victory_Screen e desenhe a tela final.
  • Use o mesmo gatilho do Boss: quando eu receber boss down.
  • Adicione os blocos mostre, toque o som [Win] e, em seguida, pare [todos].
