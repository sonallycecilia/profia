Melhorando o Jogo: Telas e Desafios

Um bom jogo precisa ficar mais difícil com o tempo e ter telas bem desenhadas para guiar o jogador. Vamos entender como melhorar o nosso projeto para deixá-lo com cara de jogo profissional!

O Problema das Vidas no Código Antigo

Se você tentou colocar uma variável de "Vidas" no nosso antigo código de colisão (aquele do juiz), deve ter notado que o jogo quebrou. Isso acontece por dois motivos muito importantes na lógica de programação:

  • O Efeito Metralhadora: O bloco "sempre" verifica as batidas dezenas de vezes por segundo. Se o personagem encostar no cano por apenas um segundo, o computador vai subtrair 30 vidas de uma vez só! Faltou criar um "tempo de invencibilidade" para ele piscar e se recuperar após o dano.
  • O Feitiço de Gelo: O nosso código antigo usa o bloco "pare outros scripts no ator" logo depois que bate. Isso congela as asas e a gravidade na hora. Para um sistema de vidas funcionar, o personagem precisaria perder uma vida, voltar para o ponto de início e continuar voando normalmente.

Adicionando a Tela de Game Over

Em vez de apenas congelar o pássaro, vamos criar uma tela de Fim de Jogo que aparece no momento exato da batida, cobrindo todo o cenário.

TELA DE DERROTA (Novo Ator)
Quando bandeira verde for clicado
 ➜ esconda

Quando eu receber player dead
 ➜ vá para a camada da frente
 ➜ mostre
 ➜ pare todos
Como Funciona?

Você deve criar um novo Ator desenhando a frase "Game Over". Quando o jogo começa, ele se esconde e fica invisível. Ele fica apenas aguardando o juiz transmitir a mensagem secreta de derrota. Ao ouvir o sinal, ele pula para a frente da tela e encerra todo o jogo de forma elegante.

Deixando os Canos Mais Difíceis

Para deixar o jogo mais desafiador, que tal fazer alguns canos se moverem para cima e para baixo sozinhos enquanto deslizam para a esquerda?

CANOS MÓVEIS (Dificuldade Alta)
Quando eu começar como um clone
 ➜ sempre
deslize em 1 segs para x: posição x y: 50
deslize em 1 segs para x: posição x y: -50

Este código é adicionado na parte onde os clones dos canos nascem. O bloco de deslizar faz o cano subir até a altura 50 e depois descer até a altura -50 de forma suave, forçando o jogador a ter muito mais reflexo na hora de passar pelo buraco.

Desafio Criativo: Em vez de mover os canos, desenhe um inimigo novo, como um morcego ou uma nuvem de tempestade voando pela tela, e adicione ele na lista de batidas do juiz!
